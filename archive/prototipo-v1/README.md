# Ilha do Conhecimento — protótipo do menu

Abra `index.html` no navegador. Funciona localmente, sem instalação, servidor, bibliotecas ou JSON.

- Iniciar: mostra uma prévia da ilha e um aviso de demonstração.
- Tutorial: apresenta os controles previstos e informa que o gameplay ainda não está ativo.
- Configurações: abre o livro; os volumes podem ser ajustados e ficam preservados enquanto a página estiver aberta. Não há áudio nesta etapa.
- Sair: oferece a saída da demonstração e permite retornar ao menu. Navegadores não permitem que uma página comum feche a própria aba.
- Escape, o botão de fechar e um clique fora fecham os diálogos. O menu funciona também com Tab e Enter.

As imagens são recortes temporários dos PDFs fornecidos: quarto e livro do documento semifinal; ilha do documento de assets polidos. Botões HTML transparentes cobrem os botões desenhados. Os sliders são elementos HTML sobre a imagem do livro. A separação definitiva dos assets fica para a próxima etapa.
